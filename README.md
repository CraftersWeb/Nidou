# 🌱 Nidou

### L’essentiel au même endroit.

Nidou est une application mobile pensée pour simplifier la vie des parents en centralisant les informations scolaires de leurs enfants dans une seule interface.

> 📱 **Projet actuellement en phase de démonstration (Demo).**

## ✨ Concept

Nidou vise à réunir au même endroit les informations provenant de différentes plateformes scolaires, notamment :

- 📚 PRONOTE
- 🏫 Skolengo
- 📝 Devoirs et évaluations
- 📅 Emploi du temps
- 🔔 Notifications importantes
- 🤖 Résumés intelligents
- 👨‍👩‍👧 Gestion de plusieurs enfants

L'objectif est de proposer une expérience **simple, claire et agréable**, sans avoir à jongler entre plusieurs applications.

## 🚧 État du projet

**Version actuelle : Demo**

L'interface et l'expérience utilisateur sont actuellement en cours de développement. Les fonctionnalités présentées dans la démo sont principalement destinées à illustrer le concept et le futur fonctionnement de Nidou.

## 🎨 Design

Nidou utilise une identité visuelle basée sur différentes nuances de vert, avec une interface moderne, minimaliste et pensée avant tout pour la simplicité.
